# FitTrack AI - Frontend 🏋️‍♂️✨

React 18 + Vite frontend for FitTrack AI, featuring modern obsidian glassmorphism UI, real-time biometrics tracking, interactive weight logging charts, and an AI Fitness Coach.

## 🚀 Live Production Deployment
- **Frontend App**: [https://fittrack-ai-frontend-srujan.vercel.app](https://fittrack-ai-srujan.vercel.app)
- **Backend API**: [https://fittrack-ai-backend-kwax.onrender.com/api](https://fittrack-ai-backend-kwax.onrender.com/api)

## 🛠 Local Setup
```bash
npm install
npm run dev
```

## 📦 Build for Production
```bash
npm run build
```
